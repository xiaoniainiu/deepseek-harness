## 触发条件

Phase 2 评审通过（[H2] 用户确认方案可行）且满足以下任一条件：

| 触发信号 | 说明 |
|---------|------|
| 新服务/新模块创建 | 从零搭建一个新服务或新业务模块 |
| 3+ 微服务改动 | 变更横跨 3 个或以上服务 |
| 数据库 schema 变更 | 新建表 / 修改表结构 / 数据迁移 |
| 新外部系统对接 | 首次接入新的外部 API / MQ / RPC |
| 标记为重大重构 | 人工判定 or Phase 1 标注 |

**跳过条件**：单服务功能修改（无 schema 变更）、Bug fix、配置调整、UI 调整、Phase 1 模式 C。

## 输入

| 来源 | 必须 | 说明 |
|------|------|------|
| `requirement.md` | 是 | Phase 1 需求分析文档 |

## 设计类型选择

MIT 标准支持两种拆分方式，项目不大时可合并使用本模板：

| 类型 | 关注点 | 适用场景 |
|------|--------|---------|
| **架构设计** | 高层结构、系统关系、数据流、接口 | 新系统、大重构、跨系统集成 |
| **详细设计** | 实现细节、数据结构、算法、模块设计 | 模块级改造、复杂算法、性能优化 |
| **合并（本模板）** | 两者兼顾 | 中等规模项目（推荐默认） |
