# 设计质量视角评审

> 不是"好不好看"，是"用户能不能顺利完成任务、系统是否一致、有没有偷懒用 AI 模板"。
> 来源：7 维评分 + AI Slop Detection），适配 HiUI + EAM。

## 触发条件

由路由表控制（`README.md` §需求分级路由 → "设计质量评审"行）：
- **L1/L2**：涉及 UI 变更时**强制**
- **L3**：涉及 UI 变更时**建议**（AI 提示，用户决定是否执行）
- **L4**：跳过

"涉及 UI 变更"的判定：需求中有前端 task / 涉及新页面或页面改动 / 用户可见的交互变化。

## 7 维评审

每个维度 **0-10 分**，低于 7 分的维度必须说明"怎么做到 10 分"。

### D1：信息架构（Information Architecture）

| 分数段 | 含义 |
|--------|------|
| 8-10 | 用户能在 3 步内找到目标，层次自然 |
| 5-7 | 能找到但需要思考，某些路径不直觉 |
| 0-4 | 迷路、找不到、层次混乱 |

**检查点**：
- 导航路径是否符合 EAM 现有信息架构（参考 `docs/reference/routes.md`）？
- 新页面在菜单中的位置是否合理？
- 面包屑 / 返回路径是否完整？

### D2：交互状态覆盖（Interaction State Coverage）

| 分数段 | 含义 |
|--------|------|
| 8-10 | 空态、加载、成功、错误、边界、权限不足全覆盖 |
| 5-7 | Happy path 完整，部分异常状态缺失 |
| 0-4 | 只有 happy path |

**检查点**：
- 列表为空时显示什么？
- 接口超时/失败时显示什么？
- 无权限时显示什么？
- 数据量极大（1000+ 条）时表现如何？

### D3：用户旅程（User Journey）

| 分数段 | 含义 |
|--------|------|
| 8-10 | 从入口到完成流畅，关键步骤有引导 |
| 5-7 | 能完成但某些步骤卡壳 |
| 0-4 | 流程断裂、用户不知道下一步 |

**检查点**：
- 用户从哪个入口进来？入口是否明显？
- 每一步操作后，用户知道发生了什么吗（反馈）？
- 操作成功/失败后，用户知道下一步做什么吗？

### D4：AI 模板风险（AI Slop Detection）

> 检测方案是否使用了 AI 生成的通用模板，缺乏针对性设计。

**11 个 Slop 信号**：
1. 紫色/蓝紫渐变背景
2. 三列对称特性展示
3. 彩色圆圈中的图标
4. 全部相同的 border-radius
5. 装饰性 blob/波浪背景
6. 通用 hero 文案（"强大的 XX 管理"）
7. 千篇一律的区块节奏（标题-描述-按钮重复）
8. 无差别的卡片阴影
9. 纯装饰性的插图/图标
10. 没有数据支撑的统计数字展示
11. 生硬的渐变色 CTA 按钮

| 分数段 | 含义 |
|--------|------|
| 8-10 | 设计有针对性，不像 AI 模板 |
| 5-7 | 有 1-2 个 slop 信号 |
| 0-4 | 明显是 AI 模板堆砌 |

### D5：设计系统一致性（Design System Alignment）

| 分数段 | 含义 |
|--------|------|
| 8-10 | 完全遵循 HiUI + EAM 现有规范 |
| 5-7 | 大部分一致，个别组件/间距偏离 |
| 0-4 | 混用多种风格 |

**检查点**：
- 使用的组件是否都在 HiUI 组件库中？（参考 `docs/reference/hiui/`）
- 间距、字号、色彩是否与现有页面一致？
- 交互模式（弹窗/抽屉/跳转）是否与同类功能一致？

### D6：响应式 & 可访问性

| 分数段 | 含义 |
|--------|------|
| 8-10 | 桌面端完美，窄屏可用，键盘可操作 |
| 5-7 | 桌面端正常，窄屏部分功能不可用 |
| 0-4 | 窄屏崩掉 |

**EAM 特殊说明**：企业系统以桌面端为主，但不能在 1280px 以下完全不可用。

### D7：未决设计决策

| 分数段 | 含义 |
|--------|------|
| 8-10 | 所有设计决策已确认 |
| 5-7 | 有 1-2 个"先这样，之后再说" |
| 0-4 | 多个核心设计未决 |

**规则**：每个"先这样"必须标记为待确认项，不能无声进入开发。

```markdown
## 设计质量评审

| 维度 | 得分 | 改进方向 |
|------|------|---------|
| D1 信息架构 | {N}/10 | {如果 <7 则说明改进方向} |
| D2 交互状态覆盖 | {N}/10 | ... |
| D3 用户旅程 | {N}/10 | ... |
| D4 AI 模板风险 | {N}/10 | ... |
| D5 设计系统一致性 | {N}/10 | ... |
| D6 响应式&可访问 | {N}/10 | ... |
| D7 未决设计决策 | {N}/10 | ... |

**平均分**：{X}/10
**判定**：PASS(>=7) / NEEDS_IMPROVEMENT(5-6) / FAIL(<5)
**低于 7 分的维度改进清单**：
- D{N}: {具体改进措施}
```
